Аппаратный журнал радиолюбителя: быстрый ввод связей, поиск абонентов на QRZ.ru,
расстояние и карта трассы, голосовые заметки, импорт и экспорт ADIF.
Крупный шрифт и большие кнопки, чтобы вести лог с телефона или компьютера прямо в эфире.

## Возможности

### Журнал
- При запуске лог всегда отсортирован по дате, самая свежая связь сверху. Связи сгруппированы по дням,
  поиск по позывному, имени, городу, локатору и комментарию.
- Сортировка компактными кнопками над списком: по дате, расстоянию, позывному, диапазону. Повторное нажатие меняет направление.
- Правка связи нажатием на запись. Удалить связь можно только кнопкой «Удалить» в её карточке
  (с подтверждением и кнопкой «Отменить» после удаления) — случайный свайп в списке ничего не удалит.
- Кнопка «Добавить QSO» внизу экрана, под большим пальцем. При поиске она поднимается над клавиатурой.
- Выбор нескольких записей долгим нажатием и выгрузка только их в ADIF.
- Если связь сохранена без интернета, у записи появляется кнопка ⟳: она заново запрашивает данные абонента на QRZ.ru
  и дописывает имя, город, локатор и расстояние.

### Новый QSO
- «Добавить QSO» открывает карточку «Новый QSO». Время и дата UTC подставляются сами и занимают одну строку;
  поля для правки открываются по ✎.
- Имя, город и локатор абонента подтягиваются с QRZ.ru, пока вы набираете позывной.
- Второй источник — бесплатный справочник HamQTH.com, учётная запись не нужна. Если учётной записи QRZ.ru нет,
  позывного там нет или QRZ.ru не отвечает, программа по префиксу узнаёт страну, область, зоны CQ/ITU и центр области.
  Расстояние тогда примерное и помечено «≈». Включается в настройках, по умолчанию включён. Если учётная запись
  не указана, в карточке кнопка «Настройки»; после ввода логина поиск запускается сам.
- Жёлтая плашка показывает, сколько раз уже работали с этим позывным и когда последний раз.
- Порядок полей под ввод в эфире: позывной → частота → RST. Кнопка «Далее» на клавиатуре переходит по ним.
- Вид связи, диапазон и частота подставляются из самой свежей связи в логе, их можно поменять.
- Частота сама выбирает диапазон. Вид связи и диапазон — по строке кнопок с прокруткой, выбранный всегда на виду.
- RST: цифровая клавиатура и кнопки частых отчётов (59/57/55, 599/579/559, для цифровых видов −05/−10/−15).
- Расстояние, азимут и карта трассы по дуге большого круга.
- Все поля ADIF — в раскрывающихся группах (Абонент, Связь, Моя станция, Прохождение) с числом заполненных полей.
- Ошибка показывается у самого поля. Закрыть карточку с введёнными данными можно только после подтверждения.

### Голосовые заметки
- Удерживайте «Добавить QSO», чтобы записать голос. Отпустите, и откроется карточка с записью.
- ▶ рядом с позывным проигрывает запись. Долгое нажатие на ▶ даёт корзину для удаления.
- AAC, моно, 16 кГц, 32 кбит/с: около 240 КБ на минуту.

### Карта QSO
- Все абоненты из лога на карте OpenStreetMap. Нажатие на точку открывает связь. Своя станция отмечена мишенью поверх остальных.

### Импорт и экспорт
- **ADIF (.adi)** для обмена с LogHX, UR5EQF, N1MM и другими логами. Кодировку Windows-1251 или UTF-8
  импорт определяет сам. Все поля файла сохраняются, в том числе незнакомые приложению.
- **CSV** для Excel, разделитель «;».
- При импорте повторы пропускаются: тот же позывной, минута, диапазон и вид.

### Настройки
- Разделы сворачиваются, в заголовке каждого — итог: позывной и локатор, состояние QRZ.ru, мощность и трансивер,
  число включённых диапазонов, число записей. При первом запуске открыты те, что нужно заполнить.
- Свой позывной и QTH-локатор. Кнопка «Определить локатор» находит его по карточке QRZ.ru или по городу.
- «Моя станция»: позывной, локатор, город и ниже — «Для новых записей» (мощность, трансивер, антенна, оператор…),
  они подставляются в каждую новую связь.
- Переключатели: какие диапазоны и виды связи показывать кнопками.
- Учётная запись XML API QRZ.ru с короткой инструкцией, как получить доступ, и кнопкой «Запросить доступ на QRZ.ru».
  Второй источник — HamQTH, без учётной записи.
- «Оформление»: тема как в системе, светлая или тёмная.
- Внизу — версия программы, нажатие открывает страницу проекта на GitHub. Кнопка «Проверить обновления» узнаёт
  на GitHub, есть ли версия новее; если есть — показывает, что в ней изменилось, и предлагает скачать APK.

### Оформление
- Светлая и тёмная тема: вместе с системной или выбранная в настройках. В тёмной теме весь текст светло-серый.
- Экраны проверены с увеличенным системным шрифтом: подписи не обрезаются, время и дата переносятся.
- Значок приложения: QSO и LOG шрифтом логотипа, между ними синяя черта.

## QSO-LOG для компьютера

Версии для macOS, Windows и Linux умеют то же, что Android: голосовые заметки, карта QSO, сортировка и выбор записей,
все поля ADIF, «Моя станция», выбор диапазонов и видов связи, кнопка ⟳ для связей без данных QRZ.ru, тёмная тема.
Окно в две колонки: слева лог, справа карточка связи, карта или настройки.
Новая раскладка карточки и настроек из Android 0.8.0 (частота → RST, быстрые отчёты, раскрывающиеся группы)
в версию для компьютера пока не перенесена.

Отличия от телефона:
- Голосовая заметка: удерживайте кнопку «Добавить QSO» мышью. Запись в WAV, около 1 МБ в минуту.
- Выбрать несколько записей: долгое нажатие или ⌘-щелчок (macOS) / Ctrl-щелчок (Windows, Linux).
- Удалить запись: значок корзины в строке лога, в сообщении внизу есть «Отменить».
- Клавиши: ⌘N / Ctrl+N — новый QSO, ⌘S / Ctrl+S — сохранить, Esc — закрыть карточку или отменить выбор,
  ⌘M / Ctrl+M — карта QSO, ⌘, / Ctrl+, — настройки.
- Импорт и экспорт ADIF и CSV — в меню «Файл» и в настройках. Так лог переносится между телефоном и компьютером.

## Установка на Android

1. Скачайте `QSO-LOG-*.apk` со страницы [релиза](../../releases/tag/v0.11.1).
2. Откройте файл на телефоне. Если Android спросит, разрешите установку из этого источника.
3. Новую версию ставьте поверх старой: лог и настройки сохранятся.
   До версии 0.6.2 программа называлась «QSO Log»; после обновления она просто сменит название, данные останутся.

## Установка на macOS

1. Скачайте `QSO-LOG-1.2.0-macos-arm64.dmg` со страницы [релиза](../../releases/tag/desktop-v1.2.0).
   Сборка для Mac с процессором Apple (M1 и новее).
2. Откройте DMG и перетащите QSO-LOG в «Программы».
3. Программа не подписана сертификатом Apple, поэтому первый запуск macOS заблокирует. Откройте
   «Системные настройки» → «Конфиденциальность и безопасность», внизу у сообщения про QSO-LOG нажмите
   «Всё равно открыть». В macOS 14 и старше достаточно правого щелчка по программе → «Открыть».
4. При первой голосовой заметке macOS спросит доступ к микрофону — разрешите.
   Изменить решение можно там же, в разделе «Микрофон».

Лог и настройки: `~/Library/Application Support/QSO Log`, пароль QRZ.ru — в Связке ключей.
Новую версию ставьте поверх старой, данные останутся.

## Установка на Windows

1. Скачайте `QSO-LOG-1.2.0-windows-x64.zip` со страницы [релиза](../../releases/tag/desktop-v1.2.0).
2. Распакуйте архив целиком, например в «Документы». Из самого архива программа не запустится.
3. Запустите `QSO-LOG.exe` в папке QSO-LOG. Java устанавливать не нужно, она внутри.
4. Windows покажет «Система Windows защитила ваш компьютер», потому что программа не подписана:
   нажмите «Подробнее» → «Выполнить в любом случае».
5. Если голосовая заметка не пишется: «Параметры» → «Конфиденциальность и защита» → «Микрофон» →
   включите «Разрешить классическим приложениям доступ к микрофону».

Лог и настройки: `%APPDATA%\QSO Log`, пароль QRZ.ru — в Диспетчере учётных данных.
Для обновления замените папку программы, данные останутся. Подробнее — в `README.txt` внутри архива.

## Установка на Linux (Ubuntu, Debian)

1. Скачайте `QSO-LOG-1.2.0-linux-amd64.deb` со страницы [релиза](../../releases/tag/desktop-v1.2.0).
2. Установите в терминале из папки с файлом:
   ```bash
   sudo apt install ./QSO-LOG-1.2.0-linux-amd64.deb
   ```
   Или двойным щелчком по файлу в «Центре приложений».
3. QSO-LOG появится в меню приложений (раздел «Любительское радио» / «Интернет»).
   Запуск из терминала: `/opt/qso-log/bin/QSO-LOG`.

Программа ставится в `/opt/qso-log`, Java уже внутри. Лог и настройки: `~/.local/share/qso-log`.
Пароль QRZ.ru хранится в связке ключей (GNOME Keyring, KWallet), а если её нет — в файле настроек.
Голос записывается с микрофона, выбранного в системе по умолчанию.
Удалить программу: `sudo apt remove qso-log` (лог в домашней папке останется).

## Доступ к QRZ.ru

Для поиска абонентов нужен доступ к XML API QRZ.ru. Как его получить (так же написано в настройках программы):
1. Войдите на qrz.ru. Ваш позывной должен быть в Callbook QRZ.ru.
2. Откройте «Личные данные» → внизу раздел «XML API» → «Создать аккаунт»
   ([прямая ссылка](https://www.qrz.ru/personal/settings/apiuser)).
3. Укажите свой позывной и программу: QSO-LOG.
4. Логин и пароль для XML API придут через некоторое время. Это не пароль от сайта.

Доступ дают только на постоянные позывные радиолюбителей и наблюдателей, только для личного аппаратного журнала.
Подробнее — в [справке QRZ.ru](https://www.qrz.ru/help/api/xml).
Без него приложение работает, но данные абонента придётся вписывать вручную.

## Данные и приватность

- Лог, настройки и голосовые заметки хранятся только на вашем телефоне или компьютере.
- Пароль QRZ.ru хранится в зашифрованном хранилище Android или в системной связке ключей компьютера.
- Приложение обращается в сеть только к `api.qrz.ru` (поиск позывных), к серверам тайлов OpenStreetMap (карты)
  к `hamqth.com` (страна и область по позывному, если второй источник включён) и к GitHub — только когда вы
  нажимаете «Проверить обновления».

## Сборка из исходников

Нужны JDK 17 и Android SDK (platform 34).

```bash
./gradlew :app:assembleDebug     # APK: app/build/outputs/apk/debug/app-debug.apk
./gradlew :shared:test :desktop:test   # тесты ADIF, базы и голосовых заметок
./gradlew :desktop:run           # версия для компьютера, запуск для разработки
./gradlew :desktop:screenshots   # скриншоты версии для компьютера с демо-данными → docs/screenshots
./gradlew :desktop:packageReleaseDmg   # DMG для macOS (нужен JDK 17 не из Homebrew, например Temurin)
./desktop/windows/build-windows.sh     # ZIP для Windows, собирается на Mac (см. комментарий в скрипте)
./desktop/linux/build-linux.sh         # DEB для Ubuntu/Debian, собирается на Mac через Docker
python3 desktop/icons/make_icon.py     # значки для компьютера (icns, ico, png)
```

Структура:
- `shared/` — модель QSO, расчёт расстояния и азимута, ADIF, CSV, клиент QRZ.ru (чистый Kotlin/JVM);
- `app/` — Android-приложение (Jetpack Compose, Material 3, SQLite, osmdroid);
- `desktop/` — macOS, Windows и Linux (Compose Multiplatform, SQLite, своя карта на тайлах OpenStreetMap, запись голоса через Java Sound).

## Известные ограничения

- Сборка Android не подписана ключом для Google Play: это отладочная (debug) сборка для установки вручную.
- Сборки для macOS и Windows не подписаны сертификатами Apple и Microsoft, система предупредит при первом запуске.
- Версия для Windows собрана на Mac и на самой Windows не проверялась. Пакет для Linux проверен в Ubuntu 24.04
  (установка, запуск, удаление), но без микрофона. Если что-то не работает, откройте issue.
- Тёмная тема на компьютере включается вместе с системной в macOS и Windows; в Linux программа всегда светлая.
- При мелком масштабе подписи соседних станций на карте QSO могут накладываться друг на друга.
- Голосовые заметки не попадают в файлы экспорта и между телефоном и компьютером не переносятся.
