Аппаратный журнал радиолюбителя: быстрый ввод связей, поиск абонентов на QRZ.ru,
расстояние и карта трассы, голосовые заметки, импорт и экспорт ADIF.
Крупный шрифт и большие кнопки, чтобы вести лог с телефона прямо в эфире.

## Возможности

### Лог
- Связи сгруппированы по дням, поиск по позывному, имени, городу, локатору и комментарию.
- Сортировка кнопками над списком: по дате, расстоянию, позывному, диапазону. Повторное нажатие меняет направление.
- Правка связи нажатием на запись, удаление свайпом влево с кнопкой «Отменить».
- Выбор нескольких записей долгим нажатием и выгрузка только их в ADIF.
- Если связь сохранена без интернета, у записи появляется кнопка ⟳: она заново запрашивает данные абонента на QRZ.ru
  и дописывает имя, город, локатор и расстояние.

### Новый QSO
- «Добавить QSO» открывает карточку «Новый QSO». Дата и время UTC подставляются сами.
- Имя, город и локатор абонента подтягиваются с QRZ.ru, пока вы набираете позывной.
- Жёлтая плашка показывает, сколько раз уже работали с этим позывным и когда последний раз.
- Диапазон и вид связи выбираются одной кнопкой. Если ввести частоту, диапазон определится сам.
- Расстояние, азимут и карта трассы по дуге большого круга.
- «Все поля»: область, район, зоны CQ/ITU, DXCC, QSL via, мощность, QSL, данные своей станции, SFI/A/K.

### Голосовые заметки
- Удерживайте «Добавить QSO», чтобы записать голос. Отпустите, и откроется карточка с записью.
- ▶ рядом с позывным проигрывает запись. Долгое нажатие на ▶ даёт корзину для удаления.
- AAC, моно, 16 кГц, 32 кбит/с: около 240 КБ на минуту.

### Карта связей
- Все абоненты из лога на карте OpenStreetMap. Нажатие на точку открывает связь.

### Импорт и экспорт
- **ADIF (.adi)** для обмена с LogHX, UR5EQF, N1MM и другими логами. Кодировку Windows-1251 или UTF-8
  импорт определяет сам. Все поля файла сохраняются, в том числе незнакомые приложению.
- **CSV** для Excel, разделитель «;».
- При импорте повторы пропускаются: тот же позывной, минута, диапазон и вид.

### Настройки
- Свой позывной и QTH-локатор. Кнопка «Определить локатор» находит его по карточке QRZ.ru или по городу.
- «Моя станция» (мощность, трансивер, антенна, оператор…) подставляется в каждую новую связь.
- Переключатели: какие диапазоны и виды связи показывать кнопками.
- Учётная запись QRZ.ru XML API.
- Внизу — версия программы, нажатие открывает страницу проекта на GitHub.

### Оформление
- Светлая и тёмная тема переключаются вместе с системной. В тёмной теме весь текст светло-серый.
- Значок приложения: QSO и LOG шрифтом логотипа, между ними синяя черта.

## QSO-LOG для Windows и macOS

Окно в две колонки: слева лог с поиском, справа карточка связи или настройки.

- Поиск абонента на QRZ.ru, подсветка повторных связей, расстояние, азимут и карта трассы (OpenStreetMap).
- Правка и удаление связей с кнопкой «Отменить».
- Импорт и экспорт **ADIF** и **CSV** в меню «Файл». Так лог переносится между телефоном и компьютером,
  все поля ADIF сохраняются.
- Клавиши: ⌘N / Ctrl+N — новая связь, ⌘S / Ctrl+S — сохранить, Esc — закрыть карточку, ⌘, / Ctrl+, — настройки.
- Пароль QRZ.ru хранится в Связке ключей macOS или в Диспетчере учётных данных Windows.

Чего пока нет по сравнению с Android: голосовых заметок, карты всех связей, сортировки лога, выбора записей
для экспорта, раздела «Все поля» в карточке, настроек «Моя станция» и выбора диапазонов (показываются основные).

**macOS:** откройте DMG и перетащите QSO-LOG в «Программы». Приложение не подписано сертификатом Apple, поэтому
при первом запуске откройте его через правый клик → «Открыть». Сборка только для Apple Silicon (M1 и новее).

**Windows:** распакуйте ZIP целиком, например в «Документы», и запустите `QSO-LOG.exe`. Java уже внутри.
Windows покажет «Система Windows защитила ваш компьютер», потому что программа не подписана:
нажмите «Подробнее» → «Выполнить в любом случае». Подробнее — в `README.txt` внутри архива.

## Установка на Android

1. Скачайте `QSO-LOG-*.apk` со страницы [релиза](../../releases/tag/v0.7.0).
2. Откройте файл на телефоне. Если Android спросит, разрешите установку из этого источника.
3. Новую версию ставьте поверх старой: лог и настройки сохранятся.
   До версии 0.6.2 программа называлась «QSO Log»; после обновления она просто сменит название, данные останутся.

Для поиска абонентов нужен доступ к XML API QRZ.ru. Его выдают в личном кабинете QRZ.ru → «Личные данные» → XML API.
Без него приложение работает, но данные абонента придётся вписывать вручную.

## Данные и приватность

- Лог, настройки и голосовые заметки хранятся только на телефоне.
- Пароль QRZ.ru хранится в зашифрованном хранилище Android.
- Приложение обращается в сеть только к `api.qrz.ru` (поиск позывных) и к серверам тайлов OpenStreetMap (карты).

## Сборка из исходников

Нужны JDK 17 и Android SDK (platform 34).

```bash
./gradlew :app:assembleDebug     # APK: app/build/outputs/apk/debug/app-debug.apk
./gradlew :shared:test           # тесты ADIF
./gradlew :desktop:run           # версия для компьютера, запуск для разработки
./gradlew :desktop:packageReleaseDmg   # DMG для macOS (нужен JDK 17 не из Homebrew, например Temurin)
./desktop/windows/build-windows.sh     # ZIP для Windows, собирается на Mac (см. комментарий в скрипте)
```

Структура:
- `shared/` — модель QSO, расчёт расстояния и азимута, ADIF, CSV, клиент QRZ.ru (чистый Kotlin/JVM);
- `app/` — Android-приложение (Jetpack Compose, Material 3, SQLite, osmdroid);
- `desktop/` — Windows и macOS (Compose Multiplatform, SQLite, своя карта на тайлах OpenStreetMap).

## Известные ограничения

- Сборка Android не подписана ключом для Google Play: это отладочная (debug) сборка для установки вручную.
- Сборки для macOS и Windows не подписаны сертификатами Apple и Microsoft, система предупредит при первом запуске.
- Версия для Windows собрана на Mac и на самой Windows не проверялась. Если что-то не работает, откройте issue.
- При мелком масштабе подписи соседних станций на карте связей могут накладываться друг на друга.
- Голосовые заметки не попадают в файлы экспорта.
