QSO-LOG для Windows 10/11 (64 бит)

Установка
1. Распакуйте архив целиком, например в C:\Program Files\QSO-LOG
   или в папку «Документы». Не запускайте программу прямо из архива.
2. Запустите «QSO-LOG.exe». Java ставить не нужно, она уже лежит в папке runtime.
3. Windows может показать окно «Система Windows защитила ваш компьютер».
   Так бывает с программами без подписи разработчика. Нажмите «Подробнее»,
   потом «Выполнить в любом случае». Это нужно сделать один раз.
4. Для удобства создайте ярлык: правой кнопкой по «QSO-LOG.exe» →
   «Показать дополнительные параметры» → «Отправить» → «Рабочий стол (создать ярлык)».

Голосовые заметки
Удерживайте кнопку «Добавить QSO» мышью, пока говорите. Когда отпустите, откроется карточка с записью.
Если запись не идёт, разрешите доступ к микрофону: «Параметры» → «Конфиденциальность и защита» →
«Микрофон» → «Разрешить классическим приложениям доступ к микрофону».

Где хранятся данные
Журнал и настройки лежат в папке %APPDATA%\QSO Log, голосовые заметки там же, в папке audio.
Пароль QRZ.ru хранится в Диспетчере учётных данных Windows, запись называется «QSO Log».
Чтобы обновить программу, просто замените её папку. Журнал при этом не пропадёт.

Клавиши и мышь
Ctrl+N — новая связь, Ctrl+S — сохранить, Esc — закрыть карточку, Ctrl+M — карта, Ctrl+, — настройки.
Несколько связей выбираются Ctrl-щелчком или долгим нажатием. Их можно выгрузить в ADIF, CSV или ЕРМАК.
