QSO Log для Windows 10/11 (64 бит)

Установка
1. Распакуйте архив целиком, например в C:\Program Files\QSO Log
   или в папку «Документы». Не запускайте программу прямо из архива.
2. Запустите «QSO Log.exe». Устанавливать Java не нужно, она лежит в папке runtime.
3. Windows может показать окно «Система Windows защитила ваш компьютер»:
   программа не подписана сертификатом разработчика. Нажмите «Подробнее»,
   затем «Выполнить в любом случае». Это нужно сделать один раз.
4. Для удобства создайте ярлык: правой кнопкой по «QSO Log.exe» →
   «Показать дополнительные параметры» → «Отправить» → «Рабочий стол (создать ярлык)».

Где хранятся данные
Лог и настройки: %APPDATA%\QSO Log (qsolog.db, settings.properties).
Пароль QRZ.ru хранится в Диспетчере учётных данных Windows (запись «QSO Log»).
При обновлении программы просто замените папку, данные останутся.

Клавиши
Ctrl+N — новая связь, Ctrl+S — сохранить, Esc — закрыть форму, Ctrl+, — настройки.
