    Моя станция

    Обмен данными

    Файл ADIF подходит для LoTW (через TQSL), eQSL, Club Log, QRZ.com, HAMLOG и программ QSO-LOG для Android и компьютера.

    Трансивер (CAT)

    Через USB-кабель трансивера, в Chrome или Edge на компьютере. Новая карточка берёт частоту, диапазон и вид с трансивера.

    Этот браузер не умеет работать с COM-портами (Web Serial). CAT доступен в Chrome и Edge на компьютере.

    О программе

    QSO-LOG Web — облегчённая версия для браузера. Всё хранится только в этом браузере, на сервер ничего не уходит. Полная версия с поиском по QRZ.ru, онлайн-журналами, WSJT-X, DX-кластером и голосовыми заметками — для Android, Windows, macOS и Linux: qso-log.ru · GitHub

    Enter — записать, Esc — закрыть.
